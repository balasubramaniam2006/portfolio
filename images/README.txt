To add your profile photo to the portfolio:

1. Save the attached image file as `profile.png` in this folder:
   images/profile.png

2. In VS Code you can drag & drop the image into the `images` folder in the Explorer.

3. The portfolio already references `images/profile.png` in `index.html`. After placing the file, refresh the page in your browser to see the new profile photo.
